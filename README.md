# Spring Boot Java 8 sample

A minimal Maven project using Spring Boot 2.7.18, which supports Java 8.

## Requirements

- JDK 8
- Maven 3.6.3 or newer

## Run

From this directory:

```bash
mvn spring-boot:run
```

Open `http://localhost:8080/` to see the greeting.

## Test and package

```bash
mvn test
mvn package
java -jar target/spring-boot-java8-0.0.1-SNAPSHOT.jar
```
